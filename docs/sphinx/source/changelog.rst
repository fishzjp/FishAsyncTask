版本 0.3.0 (2026-03-05)
-----------------------

重大变更
~~~~~~~~

* **默认 Rust 实现**：Rust 核心实现作为默认选项，显著提升性能
* **架构重构**：将核心功能模块化，提高代码可维护性
* **优先级队列**：新增 PriorityTaskManager，支持基于优先级的任务调度

新增功能
~~~~~~~~

* 任务优先级支持（1-10 级，10 最高）
* 自适应工作线程伸缩
* 资源监控功能（CPU、内存）
* 分片状态存储，提高并发性能
* 批量状态更新，减少锁竞争
* 任务取消功能

性能优化
~~~~~~~~

* Rust 扩展提供 5-10x 性能提升
* 优化状态存储，减少内存占用
* 改进工作线程调度算法

Bug 修复
~~~~~~~~

* 修复 GIL 释放问题
* 修复批量 API 的并发问题
* 修复任务状态不一致的问题
