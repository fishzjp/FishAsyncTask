**日期**: 2026-03-04
**版本**: 0.2.3
**Python**: 3.11.12
**平台**: macOS (aarch64)

---

## 1. 基准工作负载结果

### 5000 任务提交测试
- **提交吞吐**: 92,685 tasks/s
- **提交时间**: 0.054s
- **总完成时间**: 0.663s

## 2. Rust vs Python 性能对比

### 状态存储 (ShardedTaskStatus)

| 操作 | Rust | Python | 加速比 |
|------|------|--------|--------|
| 顺序写入 | 1.93M ops/s | 1.79M ops/s | **1.08x** |
| 并发写入 (16线程) | 1.79M ops/s | 1.47M ops/s | **1.22x** |
| 顺序读取延迟 | 0.0005ms (平均) | 0.0008ms (平均) | **1.63x** ↓ |
| 并发读取 (100线程) | 1.38M QPS | 1.07M QPS | **1.29x** |

### 优先级队列 (PriorityTaskQueue)

| 操作 | Rust | Python | 加速比 |
|------|------|--------|--------|
| Put 操作 | 1.30M ops/s | 603K ops/s | **2.16x** |
| Get 操作 | 1.30M ops/s | 705K ops/s | **1.85x** |

### 内存占用

| 实现 | 5000 条目内存 | 每条目 | 节省 |
|------|---------------|--------|------|
| Rust | 0.3 KB | ~0.00 Bytes | **~100%** |
| Python | 1,432 KB | 0.29 Bytes | - |

## 3. 性能分析工具

- **pyinstrument**: `tests/performance/rust_baseline/pyinstrument-report.html`

---

## 4. 关键发现

1. **Rust 在并发场景下优势明显**:
   - 并发写入: 1.22x 加速
   - 并发读取: 1.29x 加速

2. **优先级队列性能提升显著**:
   - Put: 2.16x 加速
   - Get: 1.85x 加速

3. **内存占用显著降低**:
   - Rust 实现几乎不占用 Python 堆内存

4. **顺序操作提升有限**:
   - PyO3 绑定开销在小规模操作中占主导
   - 批量 API 可进一步减少跨语言调用

---

## 5. 建议

1. **使用批量 API**: 对高吞吐场景使用 `update_status_batch`、`put_batch` 等
2. **优先使用 Rust 实现**: 并发场景下性能提升明显
3. **监控内存使用**: Rust 实现内存占用更低
